📸 4K Photo Gallery Website
A responsive web-based gallery for viewing stunning 4K photography. Features include image search, fullscreen viewing, download functionality, and links to photographers' social media profiles.

🌟 Features
🔍 Search Functionality – Quickly find photos by keyword.

📥 Download Button – Save high-resolution 4K images with one click.

🖥️ Fullscreen View – Enjoy distraction-free viewing.

🔗 Photographer Socials – Credit and connect with creators via Instagram, Twitter, etc.

💡 Responsive Design – Works great on desktop and mobile devices.

🧩 Tech Stack
- HTML5
- CSS3 
- JavaScript
- responsive web
